# Portafolio de Cristhian Rossi

Sitio personal con los proyectos de Cristhian Rossi: herramientas a medida para negocios y
análisis de datos. Es HTML y CSS hecho a mano, sin nada que compilar, publicado con
GitHub Pages.

## Verlo

En línea: <https://portafolio-cristhian-rossi.github.io/>

En local, desde la carpeta del repo:

```
python -m http.server 8090
```

y abrir <http://localhost:8090/>.
